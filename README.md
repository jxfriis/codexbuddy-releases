# CodexBuddy

A free, small Windows desktop companion for your own Codex usage.

[Website](https://codexbuddy.vercel.app/) · [Download installer](https://github.com/jxfriis/codexbuddy-releases/releases/latest/download/CodexBuddy-Setup.exe) · [Download portable app](https://github.com/jxfriis/codexbuddy-releases/releases/latest/download/CodexBuddy.exe)

## Getting started

1. Download and install CodexBuddy, or run the portable app.
2. Follow the first-run guide. Use your existing Codex sign-in or choose **Sign in with ChatGPT** and complete sign-in with OpenAI in your browser.
3. Choose your corner and preferences. Press **Ctrl+Alt+C** to show or hide the window.

Requires Windows 10 or 11 (x64) and a ChatGPT account with Codex access. No API key is required. Each person connects their own account; credentials are not included in the downloads.

## Features

- Five-hour and weekly allowance, reset countdowns, and remaining percentage
- Compact and expanded views, a tray icon, and a global show/hide shortcut
- Dragging, corner snapping, position lock, and optional always on top
- Light, dark, and system appearance
- Optional vibrant usage colors, with a gentle red glow below 25%

CodexBuddy is free. Your OpenAI plan and its limits are separate. This is an independent companion, not affiliated with OpenAI.

## Downloads and verification

Installers are published in [GitHub Releases](https://github.com/jxfriis/codexbuddy-releases/releases). This build is unsigned, so Windows may show a publisher warning. Each release includes **SHA256SUMS.txt**; the release workflow verifies the files before publishing.

This repository hosts release downloads and publishing metadata, not desktop account data or the Timeless website font files.
